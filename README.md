Forecasts how many people watch Grand Theft Auto VI live on Twitch in each hour of its release day, 2026-11-19 (UTC), from the first hour's print: a rolling-midnight median ratio curve fitted live from past big launches, blended with a log-level regression on hour-1 size, with an honest per-hour spread. Python 3.13 standard library only, deterministic, offline.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
